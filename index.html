Prompt & Pray vs. Attributed Causality

Why modern enterprise AI agents fail in production, and how DIS provides structural guardrails.

The Status Quo: Prompt & Pray

Unconstrained Agent Chaos

[Prompt] ──► [LLM Inference] ──► [Unbounded Tool Call] ──► 💥 Liability
  • Ambient permissions grant root access to enterprise APIs.
  • Natural language prompt injections hijack tool invocation.
  • Hallucinated entities and modes mutate databases silently.
  • Zero verifiable audit receipts for compliance or legal review.
The Standard: Governed DIS

Attributed Causal Execution

[Input] ──► [Triplet: Role × Entity × Mode] ──► [SHACL Gate] ──► ✓ Proven Action
  • Strict segregation of duties enforced by W3C SHACL shapes.
  • UtterancePolicy states what an agent must and must not say, with STRUCTURAL, INSTRUCTED or ADVISORY enforcement.
  • Side effects are declared: a mutating endpoint must name the entity it writes.
  • SPARQL audit queries list ungoverned triplets and medical-liability constructs.

DIS 1.8 Formal Semantic Extensions

Six grammar fixes from the Argus trial give a triplet executable provenance: what it reaches, what it mutates, and what it is allowed to call.

G1 · Mode / Mutates

Mode / Mutates Consistency

A READ triplet cannot bind a function whose endpoint mutates; CREATE, UPDATE and DELETE triplets must bind one that does.

G2 · Side Effects

Directed Side Effects

A function calling a mutating endpoint declares the entity it changes with writesEntity, and the triplet's target must match readsEntity or writesEntity.

G3 · Binding

Binding Completeness

A triplet with no executable function declares a bindingStatus (BOUND, MANUAL_PROCEDURE or ABSTRACT_UNBOUND) and an unboundReason, so a human step or roadmap gap is stated, not implied.

G4 · Transport

Multi-Transport Systems Layer

Endpoints declare a transport (HTTPS, MQTT, RTSP, NATS, gRPC and more), and an Application declares a networkScope so private-network systems can be modeled.

G5 · Gates

Function-Level Access Gates

An access gate can name the exact catalog functions a role may run on an entity with allowedFunction, so “may disable, may not re-enable” can be stated.

G6 · Conformance

Single-Graph Conformance

A dossier is validated as one merged graph with the DIS vocabulary; scripts/validate-dossier.sh is the canonical recipe.

CI · 196 Tests

Automated Conformance Suite

Validated with pytest, pySHACL and CUE. 196 automated tests cover the grammar, the shapes, the SPARQL queries and every reference dossier.
