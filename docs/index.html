Technical Reference & Formal Grammar

The Domain Intelligence Schema (DIS) is an open, platform-agnostic standard for enterprise agentic systems. Rooted in W3C RDF and SHACL knowledge graphs, DIS provides formal mathematical guardrails, attributed causality, and substrate-independent execution across any input channel or legacy backend.

1. Architecture & The Semantic Stack

Traditional agent frameworks treat domain knowledge as prompt injections or unstructured tool schemas. DIS moves domain authority into a formal, validating semantic knowledge graph.

W3C RDF / Turtle

Knowledge Graph Substrate

Every entity, role, mode, and execution binding is formally defined as an attributed triple in a closed semantic graph.

W3C SHACL

Structural & Behavioral Gates

Shapes Constraint Language (SHACL) acts as the execution firewall. If an agent proposes an invalid triplet or breaks segregation of duties, the shape validator rejects it deterministically.

SPARQL

Causal Audit Queries

Four standardized SPARQL queries audit full causal lineages, medical liability boundaries, ungoverned triplets, and structural integrity without runtime dependencies.

2. The Governed Agentic Triplet

At the heart of DIS is the Agentic Triplet: the atomic unit of agent capability. An agent cannot invoke an arbitrary function with ambient authority. It must execute as an authorized:

ROLE (Who Acts) × ENTITY (What Noun) × MODE (Which Verb)

The 7 Canonical Modes: CREATE, READ, UPDATE, DELETE, INITIATE, RESPOND, and NOTIFY. By constraining operations to these atomic verbs, DIS prevents hallucinated scope and forces explicit discovery of domain boundaries.

3. DIS 1.8 Grammar Extensions (G1 – G5)

Version 1.8 expands the semantic grammar to address the physical reality of multi-agent execution, epistemic drift, and legacy enterprise backends:

G1 · KNOW vs BE

Epistemic Observation vs Ground Truth

Unverified external claims are modeled as dis:Observation, carrying observer identity and epistemic confidence. Ground truth remains immutable.

G2 · HAVE & Varar

Bounded Capability Leases

Replaces ambient credentials with single-task dis:CapabilityLease mandate tokens with mathematical non-escalation invariants.

G3 · Mortalities

Thermodynamic Decay Curves

Temporal observations decay via explicit half-life curves (decayHalfLifeSeconds). Stale data triggers mandatory re-verification before state mutation.

G4 · Consensus

Disagreement Matrices

Multi-agent epistemic arbitration rules specifying consensus thresholds, dissenting votes, and human-in-the-loop arbitration when observations conflict.

G5 · Substrates

Multi-Vendor Interchangeability

Demonstrates that governed business logic compiles identically into competing legacy backends (e.g., Epic vs. Cerner vs. MEDITECH) with zero model rework.
